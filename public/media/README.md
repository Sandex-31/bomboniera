# Screenshot e video

Metti qui le immagini referenziate da `src/data/projects.ts` e `src/data/thesis.ts`.

I percorsi nei file dati sono relativi a questa cartella, per esempio:

    media: [{ src: "media/distributed-1.png", alt: "Architettura del sistema" }]

Formati supportati: png, jpg, webp, mp4, webm.
Se un file manca, la scheda mostra un segnaposto e l alt text — l app non si rompe.

Consiglio: esporta a larghezza massima 1200px e comprimi (webp o jpg qualità 80),
la bomboniera si apre da rete mobile.
